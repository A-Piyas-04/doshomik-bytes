Hosting and domain are already available.

The application will use the existing Hostinger VPS, with dedicated application services, database credentials, media storage, and deployment configuration.

How the system works
The Android app communicates with the Node.js backend using HTTPS.
PostgreSQL stores user accounts, creator profiles, posts, courses, quizzes, research references, and interactions.
Uploaded videos, images, and files are stored on the VPS.
Redis and FFmpeg handle video processing in the background.
The backend manages authentication, content, search, learning progress, and permissions.
An admin dashboard manages users, reported content, and moderation.

Initial Reels will support videos up to 60 seconds, with controlled upload sizes and optimized playback.

The architecture will support a future iOS application using the same backend.
