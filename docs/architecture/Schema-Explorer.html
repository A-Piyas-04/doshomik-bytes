Grouped by the table being referenced, so the hubs stand out. The delete rule says what happens to the child row when the parent row is deleted.

cascade child row is deleted too set null child row kept, link forgotten restrict delete refused while referenced (409 IN_USE)
Three columns hold an id with no foreign key, on purpose, because the row must outlive its target: reports.target_id, outbox_events.entity_id and audit_log.entity_id.

5 Indexes beyond primary keys and unique constraints

Partial indexes carry their WHERE clause, which keeps the feed and queue indexes small. A query only uses a partial or expression index when its condition matches the index's.

The full-text expressions in src/db/search.ts must match the index expressions exactly, or Postgres quietly stops using the indexes.

6 What happens when a user row is deleted
